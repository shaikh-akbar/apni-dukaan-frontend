# Apni Dukaan — Frontend

React 19 + Vite + Tailwind CSS v4 single-page app: the customer rewards portal (`/`, `/me`) and the admin panel (`/admin`).

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api and /uploads to http://localhost:4000
npm run lint
npm run build    # → dist/
```

Start the backend first (`../../backend`, `npm run dev`). See the [project README](../../README.md) for setup, credentials, API reference and deployment.
